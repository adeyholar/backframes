# BackFrames

Each frame plays one chapter from a routine. Pick the video, then the frame. The player stays inside that chapter.

| Routine | Video | Presenter |
| --- | --- | --- |
| Back | [The 3 Best Back Exercises](https://youtu.be/AlZm5IKaf1U) | Dr. Michael Rowe |
| High hip | [Self Correct a High Hip](https://youtu.be/krGkT8NymA4) | Dr. Michael Rowe |
| Uneven hips | [The ONLY 2 Exercises You Need to Fix Uneven Hips](https://youtu.be/3Oc7V2xB2kQ) | Zac Cupples |

This is a viewing aid, not medical advice, and it is not affiliated with the presenters.

## Run it on your computer

```bash
npm install
npm run dev
```

Then open http://localhost:8080

## Publish it for free

GitHub Pages only serves static files. This app is a small website server, so Pages cannot host it.

The free host that matches this project is [Vercel Hobby](https://vercel.com/pricing) (no charge for a personal project):

1. Sign in at [vercel.com](https://vercel.com) with this GitHub account.
2. Choose **Add New → Project** and import `adeyholar/backframes`.
3. Leave the build command as `npm run build` and deploy.

You do not need a paid GitHub plan or a paid Vercel plan.
