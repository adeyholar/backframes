# BackFrames

Each frame plays one chapter from Dr. Michael Rowe’s video
[The 3 Best Back Exercises (For NO MORE PAIN)](https://youtu.be/AlZm5IKaf1U).
The player stays inside that chapter.

| Frame | Exercise | Clip |
| --- | --- | --- |
| 00 | The briefing | 0:00–0:11 |
| 01 | Morning stretch | 0:11–4:52 |
| 02 | Midday stretch | 4:52–7:10 |
| 03 | Strengthening | 7:10–10:18 |

This is a viewing aid, not medical advice, and it is not affiliated with SpineCare.

## Run it on your computer

```bash
npm install
npm run dev
```

Then open http://localhost:8080

## Publish it for free

The free host that matches this project is [Vercel Hobby](https://vercel.com/pricing) (no charge for a personal project):

1. Sign in at [vercel.com](https://vercel.com) with this GitHub account.
2. Choose **Add New → Project** and import `adeyholar/backframes`.
3. Leave the build command as `npm run build` and deploy.

You do not need a paid GitHub plan or a paid Vercel plan.
